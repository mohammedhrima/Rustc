# rust-todo-app

A terminal todo app written in Rust with an ncurses UI. Items load from and save back to a file
you pass on the command line; navigate and toggle them right in the terminal.

## Run

```console
cargo run <file-name>
```

Requires the system ncurses library (preinstalled on macOS and most Linux distros).
